支持格式与说明

输入识别

ChatGPT web session JSON、Codex auth.json、sub2api 导出/单账号、通用 OAuth token、OpenAI API key、OpenAI-compatible proxy、Cookie/Header。

输出导出

Codex auth.json、Codex 批量数组、批量文件包 JSON、sub2api、通用 OAuth、API env、OpenAI-compatible JSON、LiteLLM YAML、One API/New API 通道草稿、cURL、HTTPie、.env、Bearer header。

续期限制

web session 页面通常只有当前 accessToken/sessionToken，不能凭空生成 refresh_token；导出的 sub2api/Codex 只能沿用已有 token，过期后需要重新获取或提供 refresh_token。

绑定手机/MFA

是否绑定手机不能从 session JSON 稳定判断；若账号启用了额外验证，缺少 refresh_token 的转换结果更容易在 Codex 续期或校验阶段失败。
